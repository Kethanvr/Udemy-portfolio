# Udemy Portfolio Exercise

A small static HTML portfolio exercise containing a home page, an about page, a contact page, a movie-ranking example, and a birthday-invitation example. It is useful as a snapshot of early HTML practice rather than a finished personal portfolio.

## View locally

Open `index.html` in a browser. The project does not use a package manager or build tool.

Some pages still contain course-template placeholder text and example contact details. Replace those values before presenting the pages as personal information.
